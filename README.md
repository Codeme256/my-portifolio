# Mwesigwa David — Portfolio

Personal portfolio built with React + Vite + TypeScript + Tailwind CSS v4.

## Quick Start (VS Code)

### Requirements
- [Node.js 18+](https://nodejs.org/)
- npm (comes with Node) or [pnpm](https://pnpm.io/)

### Steps

```bash
# 1. Open this folder in VS Code

# 2. Install dependencies (choose one)
npm install
# or
pnpm install

# 3. Start the dev server
npm run dev
# or
pnpm dev
```

Then open **http://localhost:5173** in your browser.

## Pages

| Route | Page |
|-------|------|
| `/` | Home — hero, stats, skills & certs preview |
| `/skills` | Skills & Services (5 areas) |
| `/projects` | Projects & Deployments |
| `/certifications` | Verified Certifications |
| `/contact` | Contact channels |

## Build for Production

```bash
npm run build
# Output goes to dist/
```

## Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Framer Motion
- Wouter (routing)
- Lucide React + React Icons
- shadcn/ui components
